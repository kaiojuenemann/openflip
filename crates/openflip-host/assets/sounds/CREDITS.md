# Flap sounds

Twelve single flap landings, cut from "Split Flap Display" by ngruber on
Freesound: <https://freesound.org/s/261244/>.

License: Creative Commons 0 (public domain dedication),
<https://creativecommons.org/publicdomain/zero/1.0/>.

The cuts were made by the kinnet-studio/split-flap project
(<https://github.com/kinnet-studio/split-flap>, `examples/flap-sounds/`),
which publishes them under the same CC0 licence: each file is one flap
landing and its rattle (55–70 ms) from the original 44.1 kHz recording,
mixed to mono, high-passed at 150 Hz to remove room rumble, with a 0.3 ms
fade-in, an 8 ms fade-out and the peak normalized to 0.9. openflip uses
them unchanged.
